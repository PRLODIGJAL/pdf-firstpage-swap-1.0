# PDF 首页替换工具 v1.0 · pdf-firstpage-swap

把**人工签字后扫描上来的首页**，批量替换掉原 PDF 的第一页，另存到输出文件夹。
**原始文件只读，永不改动。**

典型场景：Excel / 系统导出的 PDF 作业指导书（WI 等受控文档），首页需要打印出来人工签字，
再扫描回传归档 —— 这个工具负责把「扫描件首页」贴回「原件」，其余页面一字不动。

本仓库是 **1.0 版**，同时收录 **macOS** 与 **Windows** 两份交付。

## 目录结构

```
mac/          macOS 版（含开发期的自测与回归脚本）
  swap_core.py                   核心逻辑层（无 GUI 依赖，可单测、可命令行调用）
  swap_app.py                    tkinter 图形界面
  setup_env.py                   环境自检 / 按需重建虚拟环境 / 启动（两平台共用同一份）
  启动PDF首页替换1.0.command         macOS 双击入口
  selftest.py                    核心自测（66 项）
  _regress/                      回归与验收脚本

windows/      Windows 交付包
  swap_core.py  swap_app.py  setup_env.py    ← 与 mac/ 逐字节一致
  启动PDF首页替换1.0.bat            日常入口（CRLF + 纯 ASCII + 无 BOM）
  重装运行环境.bat                  等价于 setup_env.py --rebuild --setup
```

> `swap_core.py` / `swap_app.py` / `setup_env.py` 这三个文件属于**程序本体，两份包逐字节一致**。
> 改代码请两边同步（`mac/_regress/sync_win_package.py` 是为此写的同步脚本）。

## 怎么跑

两个平台都是**双击启动器**即可，首次会自动准备运行环境（建 `.venv` → 装依赖 → 拉起界面），
之后每次双击秒开。

| 平台 | 入口 |
|---|---|
| macOS | `mac/启动PDF首页替换1.0.command` |
| Windows | `windows/启动PDF首页替换1.0.bat` |

**前置条件**：本机装有 Python 3.9+（Windows 安装时记得勾 `Add python.exe to PATH`）。

> ⚠️ `.venv` **不要**随包拷给别人，也不要跨电脑复制 —— 它记着创建时那台机器的 Python 绝对路径。
> 换台电脑第一次双击会自动重建，**不要**手动删掉整个文件夹重来。

命令行同样可用：

```bash
python swap_core.py --src 原件 --scan 扫描件 --out 输出 \
    [--dry-run --recursive --no-scale --overwrite --suffix _已替换 \
     --threshold 0.8 --min-original-pages 2]
```

省略 `--scan`（或与 `--src` 填同一个）＝ **同文件夹模式**。

## 界面流程

1. 选一个**工作文件夹**（原件与签字扫描件都放里面）
2. **「扫描并匹配（预览）」** —— 必须先看，红行先处理
3. **「开始替换」**

输出默认自动填成 `工作文件夹/输出_已替换`，可改。
① 区最上面的勾**默认就是开的**（一个文件夹模式）；去掉它才回到两个文件夹的模式。
右键一行可「手动指定扫描件…」「忽略此行」「这份其实是原件（改判后重新匹配）」「在访达中显示原件」。

## 文件名怎么配上的（有序降级，命中即止）

| 级别 | 判据 | 分值 |
|---|---|---|
| ① 编号精确 | 抽出文档编号后完全相同（`WI-2101` → `WI2101`、`T-2054-49` → `T205449`） | 1.00 |
| ② 名称精确 | 归一化全名相同 | 0.98 |
| ③ 名称包含 | 一方包含另一方，长度差 ≤ 12 | 0.90 |
| ④ 前缀一致 | 相同前缀 ≥ max(4, 短串 70%) | 0.85 |
| ⑤ 相似度 | `difflib` 比率 ≥ 门槛（默认 0.80，界面可调） | 动态 |

归一化会先剔掉**噪声词**（`扫描 / 签字版 / 副本 / 扫描件 / scan / signed` …）——
这些词只参与比较，**绝不进入输出文件名**。

**贪心一对一**：一份扫描件不会被两份原件共用。有候选但被抢走 → `冲突待定`；
完全没候选 → `无对应扫描件`；没用上的 → `多余扫描件`。**一律不硬配。**

## 首页替换与「贴合决策表」

```
输出 = [扫描件第 1 页] + [原件第 2..N 页]      （原件页数不变；扫描件多页只取首页）
```

比较两边**显示尺寸**（把 `/Rotate` 90/270 横放后的尺寸），比例差异阈值 `15%`：

- **贴合** → 建空白页（尺寸 = 原件首页显示尺寸），扫描页等比缩放居中 merge 进去
- **原样** → 扫描页原样作为第 1 页（比例差异 > 15%，或关了缩放开关）

> 为什么需要「原样」：真实 WI 的封面常是**整页横向扫描图且带 `/Rotate`**，
> 而签字回传的是纵向 A4。若一律缩放，纵向图会被塞进横向页面、两旁留大片白边。

## 一个文件夹模式（默认）

用户把「原件 + 签字扫描件」都放同一个文件夹，工具**按页数自动分流**：

| 序 | 规则 | 条件 | 角色 |
|---|---|---|---|
| ⓿ | 人工改判 | 路径在 `forced_roles` 里 | 指定值 |
| ① | 读不出页数 | `error` 或 `pages <= 0` | `无法判断` |
| ② | 图片即扫描件 | 后缀在 `IMAGE_EXTS` | `扫描件` |
| ③ | 页数达标即原件 | `pages >= 2`（默认） | `原件` |
| ④ | 单页即扫描件 | `pages == 1` | `扫描件` |

三条硬规矩：

1. **只认页数与文件类型，绝不认文件名** —— 真实原件名里本身就带「- 签字版」，
   让文件名参与判定会把整批原件判成扫描件。
2. **分不出来就露出来，不许消失** —— 判不了的文件以 `无法判断` 的行出现在预览表格里。
3. **不确定要标出来** —— 1 页且名字里没有扫描/签字字样 → 在「说明」列点名。

实现上是**两段式**：先按页数把角色分开（两个池子互斥）→ 再在池间按名字相似度一一配对。
顺序不能反 —— 页数是与名字无关的硬信号，不会被污染。

## 其它

- **记住上次选择**：配置持久化在 `~/.pdf_firstpage_swap.json`（Windows 为 `C:\Users\你的用户名\`），
  三个文件夹 + 全部选项 + 窗口大小一起回来；工具条上有「忘记记住的文件夹」。
  改动后 0.9 秒防抖自动落盘，关窗时也存一次。
- **输出文件名后缀**：只给输出文件加字尾，不改内容；非法字符自动剔除，限长 40。
- **覆盖策略**：默认**不覆盖** —— 重名自动 `_2` / `_3`。
- 仅支持 PDF 与图片（`jpg/png/bmp/tif/tiff/webp`）作扫描件；图片按一页处理。

改完代码必须重跑（见 `mac/_regress/`）：

| 层 | 脚本 | 规模 |

| ③ 记住上次选择 | `_regress/verify_config_memory.py` | 46 项 |
| ④ 真实语料 | `_regress/verify_real_corpus.py` | A~F 六类判据 |
| ⑤ 真实语料·同文件夹 | `_regress/verify_real_hybrid.py` | 20 项 |

| 交付包验收 | `_regress/run_win.command` | 58 项静态 + 5 条环境流程 |

> ⚠️ 回归脚本会把 GUI 配置重定向到 `/tmp`；跑界面那一步**必须放开沙箱**，
> 否则「0.9 秒自动落盘」写 `~/.pdf_firstpage_swap.json` 会被沙箱按 `file-unlink` 直接终止进程。

## 依赖

- Python **3.9+**
- `pypdf >= 3.16`（读写 PDF 页面、`Transformation` / `transfer_rotation_to_content`）
- `Pillow >= 9.0`（把图片扫描件转成一页 PDF）
- `tkinter`（标准库自带）

国内直连 PyPI 慢，`setup_env.py` 会先走清华镜像、失败再退回官方源。

## 已知限制

- 扫描件若被扫描仪命名成 `扫描_001.pdf` 这类无语义名，匹配无从下手 ——
  需改名，或用界面「手动指定扫描件…」。
- 一个文件夹模式下，**只有一页的原件会被当成扫描件**（这正是分流规则本身）；
  它会以「多余扫描件」的形式露在表格里，右键可改判成原件，
  或者把它单独放一个文件夹用两文件夹模式。
- **多页的扫描件**会被当成原件（`无对应扫描件`），同上。
- 真正的「双击 `.bat` 能不能开」只能在 Windows 上点一次才算数（Mac 上跑不了 `cmd`）。
